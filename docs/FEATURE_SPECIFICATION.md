# 쉼표 MVP 기능 명세 및 구현 현황

> 마지막 갱신: 2026-08-19  
> 이 문서는 기능 명세와 실제 구현 상태를 함께 관리한다.

## 상태 표기

| 상태 | 의미 |
| --- | --- |
| ✅ 완료 | API 또는 화면에서 실제 동작하는 기능 |
| 🟡 진행 중 | 일부 구현됐지만 전체 흐름 연결 또는 검증이 남은 기능 |
| ⬜ 예정 | 아직 구현하지 않은 기능 |

## 핵심 플로우

| 단계 | 기능 | 현재 상태 | 구현 기준 |
| --- | --- | --- | --- |
| 0 | 방문대상자 mock 데이터 | ✅ | 창신동 방문대상자 8명과 하루 3~4개 일정 seed |
| 1 | 오늘 일정·현재 폭염 상태 확인 | ✅ | 일정 조회, 현재·시간대별 날씨, 영향예보, 생활기상지수 |
| 2 | 현재 위치→방문지 이동구간 생성 | ✅ | mock 현재 위치, TMAP 보행경로, 거리·시간·ETA·경로좌표 저장 |
| 3 | 폭염 위험 판단 | 🟡 | `/risk/evaluate` 규칙 기반 fallback 및 모델 artifact 추론 구조 완료. 최종 AI artifact 연결 대기 |
| 4 | 휴식 필요 여부 분기 | 🟡 | 위험도에 따라 일반경로 또는 안전경로 추천 API 분기 완료. 누적 노출시간 자동 산출은 미완성 |
| 5 | 쿨링스팟 탐색·선정 | 🟡 | 공공 API 동기화, 기업 mock, 운영시간·추가 이동 5분 필터, 1개 추천 구현. 반경·편의시설 동률 정책 보완 필요 |
| 6 | 일반·안전경로 비교·안내 | 🟡 | 안전경로 Backend API와 프론트 카드·지도 연결 완료. 실제 API 호출 검증과 선택 기록 연결 필요 |
| 7 | 방문 진행·기록 | 🟡 | 일정 완료·상태 UI 일부 구현. 휴식 이행/미이행과 다음 구간 재판단 자동 연결 필요 |
| 8 | 업무 완료 집계 | 🟡 | DB 구조·노출시간 계산 함수 존재. 실제 로그 기반 완료 화면 집계 연결 필요 |

## 핵심 정책

| 정책 | 현재 기준 |
| --- | --- |
| 현재 위치 | GPS 대신 창신동 mock 위치를 사용한다. |
| 기본 경로 | MVP에서는 TMAP 보행경로를 기본 경로로 사용한다. |
| 위험 판단 | 최종 AI 모델이 배치되기 전에는 규칙 기반 fallback을 사용한다. 위험 단계는 `MOVE_POSSIBLE`, `REST_RECOMMENDED`, `REST_REQUIRED`이다. |
| 노출시간 | 실시간 버튼 추적이 아닌 일정 기반 시뮬레이션을 목표로 한다. 현재는 API 요청값으로 전달할 수 있다. |
| 쿨링스팟 추천 | 공공 쉼터와 기업 쿨링스팟을 통합한다. 운영 중이며 일반경로보다 추가 이동이 기본 5분 이하인 후보 중 1곳을 선택한다. |
| 휴식 시간 | 안전경로 기본 휴식시간은 10분이다. |
| 일반경로 선택 | 위험도 `REST_REQUIRED` 상태에서 일반경로를 선택하면 프론트에서 재확인 팝업을 보여준다. (구현 예정) |

## 현재 API 흐름

```text
GET /schedules/today
        ↓
POST /route-segments
        ↓
POST /routes/recommendation
        ├─ MOVE_POSSIBLE → normalRoute 반환
        └─ REST_RECOMMENDED / REST_REQUIRED
                ↓
           쿨링스팟 탐색
                ↓
           safeRoute 반환
```

### 주요 API

| API | 상태 | 역할 |
| --- | --- | --- |
| `GET /schedules/today` | ✅ | 오늘 방문일정 조회 |
| `GET /weather/current` | ✅ | 현재 위치 날씨 조회 |
| `GET /weather/hourly` | ✅ | 시간대별 날씨 조회 |
| `POST /routes/normal` | ✅ | 일반 보행경로 계산 |
| `POST /route-segments` | ✅ | 일반경로와 기상정보를 포함한 이동구간 저장 |
| `POST /risk/evaluate` | ✅ | 독립 위험도 판단 API |
| `GET /cooling-spots` | ✅ | 주변 쿨링스팟 조회 |
| `POST /routes/safe` | ✅ | 선택 또는 자동 추천 쿨링스팟 경유 안전경로 생성 |
| `POST /routes/recommendation` | ✅ | 위험 판단 후 필요 시 안전경로를 함께 추천 |

## 다음 우선순위

1. `POST /routes/recommendation` 실제 호출 검증
2. 실제 API 응답 기준 일반·안전경로 카드와 지도 표시 검증
3. 안전경로 선택·일반경로 선택·쉼터 건너뛰기 기록
4. 일정 기반 누적 야외노출시간 자동 계산
5. 방문 완료 후 다음 이동구간 재판단
6. 업무 완료 집계 화면 연결
7. 최종 AI 모델 artifact 배치 및 결과 비교

## 주의사항

- 위험도는 의료 진단이 아니라 이동·휴식 의사결정 보조 정보다.
- 외부 API 오류 시 프론트에서 데이터 조회 실패 상태를 명확하게 표시한다.
- API Key와 DB 비밀번호는 `.env` 또는 배포 환경변수에만 저장한다.
